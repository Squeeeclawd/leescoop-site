# LeeScoop visual style

Use this as the default image-generation style for LeeScoop covers, thumbnails, and simple visual assets unless Anthony explicitly says otherwise.

## Positive prompt pattern

```text
(short unique subject prompt:1.3), cel shaded, thick outlines, cute, expressive cartoon face, sharp silhouette, graphic shadows, true black, clean simple shapes, high contrast, bold readable design, polished mascot/logo illustration style, modern vector-like finish, tropical coastal energy, playful but clean, Florida-inspired color palette, using #07506F, #197894, #4FA7BC, #8BD2DE, #D94B32, #F28B42, #F7DE69, #F8F3E8, #063A52, #DDEEF1
```

## Negative prompt

```text
nsfw, muddy colors, low contrast, thin outlines, bad anatomy, extra limbs, blurry, text, watermark, dull palette, overly realistic rendering
```

## Usage rule

1. Read the event/news post first.
2. Extract the short visual subject.
3. Put that subject first and weight it like `(subject:1.3)`.
4. Append the house style exactly.
5. Avoid text/logos in generated images unless Anthony explicitly asks.
